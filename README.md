# PRO STORE

متجر إكسسوارات عربي بتصميم متجاوب، وواجهة عملاء منفصلة عن لوحة إدارة محمية باستخدام Supabase Auth وPostgreSQL وRow Level Security.

## الملفات
- `index.html`: واجهة العملاء.
- `admin.html`: تسجيل الدخول ولوحة إدارة المنتجات.
- `store.js`, `admin.js`: منطق المتجر ولوحة الإدارة.
- `styles.css`: التصميم.
- `config.js`: عنوان Supabase والمفتاح العام فقط.
- `supabase-schema.sql`: الجداول وسياسات الأمان.

## إعداد المتجر لأول مرة
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor ونفّذ كامل ملف `supabase-schema.sql`.
3. من Project Settings > API انسخ Project URL وpublishable/anon key إلى `config.js`. لا تستخدم مفتاح `service_role`.
4. من Authentication > Users أنشئ حساب الإدارة ببريد وكلمة مرور قويين.
5. انسخ UUID للحساب. في SQL Editor نفّذ الأمر التالي بعد استبدال النص بالـ UUID الحقيقي:
   ```sql
   insert into public.profiles (id, role)
   values ('PASTE_AUTH_USER_UUID_HERE', 'admin')
   on conflict (id) do update set role = 'admin';
   ```
6. فعّل استضافة GitHub Pages من Settings > Pages، واجعل النشر من فرع `main` ومجلد `/ (root)`.
7. افتح `config.js` في المستودع، واضغط Edit، وأدخل عنوان مشروعك ومفتاح الواجهة العام فقط ثم احفظ.
8. افتح رابط الموقع ثم ادخل لوحة الإدارة من `/admin.html`.

## الأمان وحدود النسخة
- لا توجد كلمات مرور أو مفاتيح خدمة سرية في الملفات.
- قاعدة البيانات تعتمد على RLS لفحص صلاحية الإدارة في كل طلب، وليس على إخفاء رابط لوحة التحكم.
- المنتجات المخفية لا تظهر للعملاء.
- إضافة الصور حاليًا عن طريق رابط صورة مباشر؛ رفع الملفات من داخل لوحة التحكم غير مضاف في هذه النسخة.
- يجب تنفيذ إعداد Supabase ومنح دور admin قبل أن تعمل إدارة المنتجات. لا تعتبر الموقع جاهزًا للبيع قبل اختبار الدخول والإضافة والتعديل من حساب إداري.
